# 📐 Charte graphique KALEFLEH — v1.0

> Document de référence visuelle. Tout élément de communication (site web, posts Instagram/Facebook/TikTok, visuels, affiches, flyers, emballages) doit respecter ces règles.

## 2. Logotype

- **Logotype principal** : le mot **KALEFLEH** en lettres capitale, police de la marque, couleur **Ambre** (`#E86A00`) ou **Ivoire** (`#FFF8EE`) selon le fond.
- **Sur fond clair** : Ambre foncé `#B85A00`.
- **Sur fond sombre** : Ambre `#E86A00`.
- **Zone de protection** : espace minimal = hauteur du « K » autour du mot.
- **Interdits** : ne jamais tourner le logo, ne jamais changer les couleurs, ne jamais refaire la police, ne jamais ajouter d'ombres portées lourdes ou de dégradés sur le mot lui-même.

## 3. Palettes de couleurs

### 3.1 Palette primaire (marque)

| Nom | Hex | Usage |
|---|---|---|
| **Ambre** | `#E86A00` | Boutons principaux, accents, CTA, soulignés |
| **Ambre foncé** | `#B85A00` | États survolés (hover), titres de sections |
| **Pêche** | `#FFA64D` | Points lumineux, dégradés doux |
| **Ivoire** | `#FFF8EE` | Textes sur fond sombre, cartes « lumière » |

### 3.2 Palette secondaire (fond)

| Nom | Hex | Usage |
|---|---|---|
| **Charbon** | `#1C1208` | Fond hero, footer, totaux |
| **Charbon doux** | `#3A1D00` | Dégradé intermédiaire hero |
| **Crème** | `#F7F1E7` | Fond de page |
| **Blanc** | `#FFFFFF` | Cartes, formulaires |

### 3.3 Couleurs sémantiques

| Nom | Hex | Usage |
|---|---|---|
| **Succès** | `#1E8E3E` | Messages de validation, coches |
| **Erreur** | `#C5221F` | Champs invalides, alertes |
| **Info neutre** | `#6B6B6B` | Textes secondaires |

### Règles d'usage
- Règle **60-30-10** : 60 % Crème/Blanc, 30 % Charbon, 10 % Ambre.
- Ne jamais mettre l'Ambre sur une autre couleur saturée (ex : Pêche sur Ambre).
- Texte jamais en Ambre sur fond clair (contraste insuffisant) → utiliser le foncé `#B85A00`.

## 4. Typographie

### 4.1 Polices
| Rôle | Police | Remplacement |
|---|---|---|
| **Titres / Hero** | **Montserrat ExtraBold (800/900)** | Arial Black |
| **Sous-titres / boutons** | **Montserrat Bold (700)** | Arial Bold |
| **Corps de texte** | **Inter (400/500/600)** | Segoe UI, Tahoma |

### 4.2 Échelle (site web)

| Élément | Taille | Poids | Graisse |
|---|---|---|---|
| Hero titre | 3.2–3.6 rem | 900 | uppercase partiel |
| H1 section | 1.7 rem | 800 | — |
| H2 section | 1.3 rem | 800 | — |
| Corps | 1.0 rem | 400 | — |
| Petits textes / notes | 0.82–0.9 rem | 500 | — |
| Boutons | 0.95–1.05 rem | 800 | — |

### 4.3 Règles
- Interligne confortable (1.5–1.6).
- Ne jamais écrire un paragraphe complet en majuscules.
- L'emphase se fait par le **poids** (700/800), pas par le soulignement.

## 6. Composants clés

### 6.1 Boutons
```
Couleur fond  : Ambre (#E86A00)   · Texte : Blanc
Hover         : Ambre foncé (#B85A00)
Rayon         : 12px · Poids : 800 · Lettrage normal
CTA principal : toujours avec un appel à l'action explicite (« Obtenir mon devis → »)
Bouton secondaire : contour Ivoire sur fond Charbon (transparent)
```

### 6.2 Champs de formulaire
```

Focus   : bordure Ambre + halo rgba(232,106,0,.15)

```

### 6.3 Cartes / sections
```
Fond : Blanc · Rayon 16px · Ombre standard
Titre de section : Ambre foncé, bord gauche 5px Ambre, uppercase
```

```
Fond : Charbon (#1C1208) · Texte : Ambre clair (#FFCF9E)
Rayon : 20px · Petit texte 0.8rem · poids 700
```

Carré arrondi 40×40 · Fond Charbon · chiffre en Ambre clair · poids 900

## 8. Ton & voix

| Context | Dire | Ne pas dire |
|---|---|---|
| Client | **tu** / **vous** ? → TOUJOURS **tu** sur le web et les posts | « cher client » |
| Rassurer | « Photos + reçus à chaque étape » | promesses vagues |
| Devis | « gratuit, sans engagement » | « ça dépend » |
| Dire non | « On ne fait pas les documents administratifs » | liste négative interminable |
| Expédition | « par ta compagnie, ou via nous » | jargon douanier |

Impact de langage : phrases courtes, 1 idée = 1 phrase, verbes d'action au début (« Commande », « On achète », « Tu reçois »).

## 9. Déclinaisons en production

| Support | Contenant |
|---|---|
| Posts carrés IG/FB | 1080×1080 (`public/affiche-carre.png`, `public/carrousel/*`) |
| Stories | 1080×1920 (`public/affiche-story.png`) |
| Site web | `public/style.css` (variables `:root`) |
| Logos / icônes / favicon | `public/favicon.svg`, `favicon.svg`, `favicon.png`, `favicon-32.png`, `apple-touch-icon.png` — Ambre sur Charbon, lettre **K** |

> **Toutes les couleurs et la typo du site sont centralisées dans les variables CSS `:root` de `public/style.css`.** Modifier la charte → modifier les variables → tout se met à jour.

### 9.1 Régénération des affiches et carrousel
Les visuels sont des SVG sources (`public/affiche-carre.svg`, `public/affiche-story.svg`, `public/carrousel/slide-*.svg`) convertis en PNG 1080px.

```bash
cd kalefleh
node tools/generate-carousel.mjs   # régénère les SVG du carrousel (après édition du contenu)
node tools/svg-to-png.mjs          # convertit tous les SVG → PNG (Chromium/Playwright, polices Google)
```

> Le carrousel (6 slides « Comment ça marche ») se modifie dans `tools/generate-carousel.mjs` (tableau `slides`) puis on relance la conversion.

### 9.2 Favicon / logo de marque
Source `public/favicon.svg` (lettre K, fond Charbon arrondi, dégradé Ambre). Rendu PNG :

```bash
cd kalefleh && npm run favicons   # génère favicon.png (128), favicon-32.png, apple-touch-icon.png
```
